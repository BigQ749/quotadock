# 官方品牌资源来源

浮窗运行时读取同目录下缓存的 PNG，不会在每次绘制时访问网络。

运行时使用 `*-mark.png`：它们是从下面官方资源提取的 logo 主体，去除不同尺寸的底板留白后统一显示，不改变 logo 图形本身。

- Codex / ChatGPT：从官方 Codex Windows 包的资源中提取 ChatGPT 标识（不包含本机安装路径或用户数据）。
- Grok：<https://grok.com/images/apple-touch-icon.png>
- OpenCode Go：<https://opencode.ai/favicon-96x96-v3.png>

资源核对并缓存日期：2026-08-11。品牌名称和标识仍归各自权利人所有；本项目仅用于识别额度来源。
