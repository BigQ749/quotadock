# QuotaDock v0.2.0

## 这次更新

- 放大 QuotaDock 中心的右键菜单和“添加其他平台”弹窗，统一文字、留白和高 DPI 缩放。
- 修复隐藏浮窗右键时，鼠标从边缘手柄移动到菜单会触发自动藏边的问题；菜单真正关闭后才恢复自动藏边计时。
- 将 Windows 端的 Codex、Grok、OpenCode Go 刷新改为约每 60 秒启动一次短同步任务，保留旧版同步脚本的兼容回退，减少三个常驻同步进程的内存占用。
- 增加 macOS 原生预览版：菜单栏入口、原生浮动面板、多平台选择和本地 `providers.json` 展示。
- 发布工作流增加 macOS 13+ 构建资产，并将其附加到同一 GitHub Release。

## 下载

- `QuotaDock-Setup-0.2.0.exe`：Windows 安装器。
- `QuotaDock-v0.2.0.zip`：Windows 便携/本地更新包。
- `QuotaDock-macOS-v0.2.0.zip`：macOS 原生预览包（Intel/Apple Silicon，macOS 13+）。
- `SHA256SUMS.txt`：Windows 资产校验值。

## macOS 预览边界

macOS 版当前读取 `~/Library/Application Support/QuotaDock/providers.json`，不复用 Windows 的 PowerShell、DPAPI、Chrome 桥接或账号同步路径。它是可运行的展示层预览，不应被理解为 Codex、Grok、OpenCode Go 真实账号同步已经在 Mac 上完成。首次发布包尚未做 Apple Developer ID 签名和公证。

## 已知事项

- Windows 的外部同步器仍需用户按平台配置，401/403、Cookie 过期和页面结构变化会显示为同步失败并保留上次成功数据。
- macOS 真实同步适配器、签名/公证和自动更新将在后续独立验证后再加入。
