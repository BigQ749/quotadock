# QuotaDock v0.2.4

## 新功能

- 将 **Grok Bot**、**Muse**、**Claude** 提升为内置目录平台（与 Codex / Grok / OpenCode Go 同级）。
- 新增品牌图：`assets/brand/grokbot-mark.png`、`muse-mark.png`、`claude-mark.png`。
- 计量卡默认读取 `%LOCALAPPDATA%\QuotaDock\custom-data\{grokbot|muse|claude}.json`，单窗口大百分比布局与 Grok 一致。
- 提供可选同步适配器说明与示例脚本（`adapters/`）；凭证与 Cookie 仍仅保存在本机。
- Claude 目前仅提供目录与数据约定，官方同步脚本待接入。

## 说明

- 升级安装后，其他电脑也会在中心看到这三张内置卡；本地同步器仍需各自机器配置。
- 若本机曾用 `custom_providers.json` 注册同名 id，内置卡优先，自定义同名项会被忽略。

## 下载

- `QuotaDock-Setup-0.2.4.exe`：Windows 安装器。
- `QuotaDock-v0.2.4.zip`：Windows 便携/本地更新包。
- `QuotaDock-macOS-v0.2.4.zip`：macOS 原生预览包（Apple Silicon arm64，macOS 13+）。
