# QuotaDock 0.1.4 · 同步时间与数据源修复版

## 这版解决什么

- 不再因为缺少本地配置而读取公开示例额度；运行时优先读取真实同步文件。
- Codex、Grok、OpenCode Go 同步器启动时会收敛为单实例，避免多个进程互相覆盖 JSON。
- 分开记录最近一次成功同步、最近一次尝试和失败原因。
- 401、认证过期、网络失败时保留最近一次有效额度，不把失败时间伪装成成功时间。
- OpenCode Go 后台同步失败或未配置凭证时，浮窗显示明确失败状态；旧数据会标记为缓存/过期。

## 验证边界

- PowerShell 7+ 脚本解析和 QuotaDock 完整自测通过。
- OpenCode Go SSR 解析器自测通过。
- Grok `monitor.py` Python AST/编译检查通过。
- 本地额度数据、Cookie 和 Token 不进入仓库或更新包。
