# QuotaDock v0.2.3

## 修复

- 修复浮窗自动藏边后，状态栏可能被其他置顶应用覆盖的问题。
- 状态栏会在失去焦点时及藏边期间重新提升到最上层，且不会抢占前台应用的输入焦点。

## 下载

- `QuotaDock-Setup-0.2.3.exe`：Windows 安装器。
- `QuotaDock-v0.2.3.zip`：Windows 便携/本地更新包。
- `QuotaDock-macOS-v0.2.3.zip`：macOS 原生预览包（Apple Silicon arm64，macOS 13+）。

Windows 安全桌面（如 UAC 提示）及独占全屏程序受系统窗口管理限制，普通桌面浮窗无法覆盖。
