# QuotaDock v0.2.1

## 修复

- 修复 macOS SwiftUI 预览版在 macOS runner 上的浮动面板尺寸声明，确保 `QuotaDock-macOS-v0.2.1.zip` 能正常构建。
- 保留 v0.2.0 的 Windows 菜单放大、右键藏边保护和短同步任务改动。

## 下载

- `QuotaDock-Setup-0.2.1.exe`：Windows 安装器。
- `QuotaDock-v0.2.1.zip`：Windows 便携/本地更新包。
- `QuotaDock-macOS-v0.2.1.zip`：macOS 原生预览包（Intel/Apple Silicon，macOS 13+）。

macOS 预览版仍然只读取 `~/Library/Application Support/QuotaDock/providers.json`，不复用 Windows 的 PowerShell、DPAPI、Chrome 桥接或账号同步路径；首次发布包尚未做 Apple Developer ID 签名和公证。
