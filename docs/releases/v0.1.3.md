# QuotaDock 0.1.3 · 本地更新与右键修复版

## 本次更新

- 本机与仓库版本统一迭代到 `0.1.3`；版本源以根目录 `VERSION` 为准。
- 更新检查改为读取公开 `update-manifest.json`，不依赖 GitHub API 的剩余配额。
- 发现新版本后可直接下载版本化 ZIP；更新器会校验 SHA-256、等待 QuotaDock 退出、备份程序目录、替换运行文件并自动重启。
- 更新失败时会尝试恢复本次备份；`%LOCALAPPDATA%\QuotaDock` 中的配置、凭据和本地额度数据不进入更新包。
- 管理中心额度卡的右键现在只打开上下文菜单；左键仍负责打开/关闭，避免右键同时触发切换。
- 增加更新包结构、版本、哈希和隐私边界的自动自测。

## 发布内容

- `QuotaDock-v0.1.3.zip`：客户端直接更新包。
- `QuotaDock-Setup-0.1.3.exe`：GitHub Actions 生成的 Windows 安装器。
- `SHA256SUMS.txt`：安装器校验文件。

## 验证范围

- PowerShell 7+：center、host、更新检查器、本地安装器自测通过。
- 右键回归：卡片标题、描述、品牌图标和开关均只在左键 MouseDown 中切换。
- 更新包回归：版本、SHA-256、运行文件齐全，且不包含 `opencode_go_live.json`。

## 安全边界

更新包只来自公开仓库的版本化文件，并在本机按清单校验 SHA-256；当前版本未加入代码签名，建议只使用仓库主线清单指向的包。Cookie、令牌和真实额度快照不提交、不打包。
