# QuotaDock v0.2.5

## 产品化

- **可滚动平台列表**：管理中心用 Panel + AutoScroll，并限制最大高度适配常见 ~1080p 工作区，6+ 内置平台不再被裁切。
- **首次运行新手引导**：本机仅显示一次三步中文叠加层（选平台 → 接同步器 → 浮窗藏边），并链到部署/适配器文档。
- **托盘帮助菜单**：新手指南、下载页、隐私说明、GitHub、当前版本。
- **空状态引导**：等待同步的计量卡可打开适配器说明；Claude 明确标注为「手动 JSON / 预览」，避免垃圾占位数据。
- **更新对话框**：发现新版本时可打开 `releaseUrl` 发布说明；仍优先走本机校验安装。

## 打包

- 安装器与便携/更新 ZIP 均包含 `adapters/`。
- 附带离线文档子集：`docs/download.md`、`docs/deployment-guide.md`、`docs/providers-grokbot-muse-claude.md`、`docs/privacy.md`、`docs/provider-adapter.md`，以及 `custom-provider.example.json`。
- 安装器增加简体中文界面（Inno `ChineseSimplified.isl`）；若本地 ISCC 缺少该语言包，请参考 `docs/download.md` 回退为英文界面构建。

## 文档与推广

- README 下载 CTA 直达 Setup 深链；补充 SmartScreen/未签名、SHA256、勿下 Source code.zip 说明。
- 中英文特性同步覆盖 Grok Bot、Muse、Claude；新增隐私说明页。

## 下载

- `QuotaDock-Setup-0.2.5.exe`：Windows 安装器。
- `QuotaDock-v0.2.5.zip`：Windows 便携/本地更新包。
- `QuotaDock-macOS-v0.2.5.zip`：macOS 原生预览包（Apple Silicon arm64，macOS 13+）。
