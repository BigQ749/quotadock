# QuotaDock 0.1.1 · Windows 修复版

这是首个面向持续使用的修复版本，重点是“窗口状态必须和实际窗口一致”。

## 修复

- 修复合体窗口关闭单个平台时可能误关整组的问题。
- 关闭/拆分卡片后立即刷新宿主状态，管理中心不再长期显示旧状态。
- 为启动中/关闭中状态增加超时回收，避免服务已经结束但 UI 仍显示“正在关闭”。
- 修复 Windows PowerShell 5.1 下菜单兼容性问题，右键菜单放大并增加圆角。
- 修复“已打开 · 已吸附”状态被卡片布局截断的问题。

## 发布内容

- `QuotaDock-Setup-0.1.1.exe`
- `SHA256SUMS.txt`

安装器支持选择目录、许可证确认和可选开机启动。当前发行版仅承诺 Windows 10/11 x64；其他架构请先查看 [下载选择指南](../download.md)。

## 安全边界

QuotaDock 不包含真实账号数据，不会把 Cookie 或额度快照上传到 GitHub。更新操作只打开公开 Release 下载页，由用户自己确认和安装。
