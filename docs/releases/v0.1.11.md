# QuotaDock v0.1.11

## 修复

- 修复桌面快捷方式在“微软商店版 PowerShell 7”（MSIX/WindowsApps 安装）机器上误报 “QuotaDock requires PowerShell 7+” 的问题。启动器现在会依次检查 Program Files、注册表 App Paths 和 `where.exe`，商店版和经典安装版都能正常拉起。
- 该问题不影响经典 MSI 安装的 PowerShell 7，但商店版用户在 0.1.10 及更早版本会遇到。

## 新增

- 新增 [新手部署指南（实测经验版）](deployment-guide.md)：覆盖环境检查、首次同步、关闭浏览器后的后台同步，以及“同步时间不更新”等真实踩坑的解决办法。
