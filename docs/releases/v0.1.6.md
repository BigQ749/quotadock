# QuotaDock v0.1.6

## 这次修复

- OpenCode Go 后台直连和 Chrome 桥接在成功写入额度快照后，会立即通知浮窗宿主重绘；正常轮询仍保持约 60 秒一次，避免把官方页面请求变成高频轮询。
- 修复完整退出 QuotaDock 后宿主浮窗仍留在桌面的生命周期问题。选择“退出 QuotaDock”会关闭单独浮窗、合体浮窗和旧版遗留浮窗，并停止 QuotaDock 自己启动的同步进程。
- “隐藏到托盘”仍只隐藏管理中心，不会关闭额度浮窗或同步器。

## 已知边界

OpenCode Go 官方页面没有向 QuotaDock 提供桌面端实时推送接口，因此显示数据不是秒级实时流。QuotaDock 采用后台约 60 秒轮询，成功后浮窗会立即重绘；`lastSuccessAt` 表示最近一次真正成功获取，认证失败或网络失败时不会伪装成新的成功时间。

## 验证

- PowerShell 7+ 脚本解析通过。
- QuotaDock 管理中心、浮窗宿主和 OpenCode Go 解析器自测通过。
- 不包含 Cookie、令牌、真实额度快照或个人凭据。
