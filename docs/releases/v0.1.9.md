# QuotaDock v0.1.9

## Windows 安装体验

- 正式区分 `QuotaDock-Setup-0.1.9.exe` 安装器和 `QuotaDock-v0.1.9.zip` 便携/更新包。
- 安装器提供欢迎页、MIT 许可证、安装盘/目录选择、桌面/开始菜单快捷方式和可选开机启动。
- 安装前检查 PowerShell 7+，缺少时给出官方安装地址。
- VBS 仅作为安装目录内的隐藏启动包装；用户从桌面或开始菜单快捷方式启动，不需要手动操作 VBS。
- Release 工作流强制校验安装器和 ZIP 都存在，避免只发布 ZIP。

## 数据与隐私

安装器和更新包不包含 Cookie、凭证文件、真实额度数据或个人路径；卸载和升级都会保留 `%LOCALAPPDATA%\QuotaDock`。
