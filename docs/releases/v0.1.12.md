# QuotaDock v0.1.12

## 发布前整理

- 移除源码分支中的历史安装包和便携 ZIP；旧版本仍可从 GitHub Releases 回退。
- 更新器改为下载对应 Release 的真实 ZIP，并校验该 Release 资产的 SHA-256。
- 发布工作流会在 Release 创建后自动回写 `main/update-manifest.json`，避免源码包与 Release 包哈希不一致。

## 修复与改进

- 修正 v0.1.11 发布说明中部署指南的链接路径。
- 增强 GitHub Release、Release 清单和 VERSION 三级更新检查兜底。
- 保留 PowerShell 7+ 启动器、安装向导、开机启动选项与本地数据保留逻辑。

## 发布内容

- `QuotaDock-Setup-0.1.12.exe`：标准 Windows 安装器。
- `QuotaDock-v0.1.12.zip`：便携版/本地更新包。
- `SHA256SUMS.txt`：下载校验值。
