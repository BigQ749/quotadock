# QuotaDock 0.1.2 · 浮窗交互修复版

## 本次更新

- 放大单卡和合体浮窗的右键菜单，统一字号、菜单项高度和圆角视觉。
- 合体浮窗右键新增“关闭其中一张额度卡片”，只移除选中的平台，不再默认关闭整个融合 host。
- 合体窗口关闭到只剩一张卡片时，自动创建真正的独立额度浮窗；继续关闭其他卡片不会把最后一张一起带走。
- 管理中心的刷新图标改为 `↑ 检查更新`，手动点击时会显示当前版本、最新版本和下载入口。
- 更新检查对 Windows PowerShell 5.1 和 PowerShell 7 统一使用 UTF-8 BOM，避免中文更新提示被系统代码页误解析。
- 增加静态回归断言，防止后续修改重新引入整组关闭和最后单卡丢失问题。

## 验证范围

- Windows PowerShell 5.1：host、center、update checker 自测通过。
- PowerShell 7：三份脚本语法解析通过。
- live host：打开三张卡后依次关闭 Grok、OpenCode Go，状态文件最终保留 Codex 单卡；host 错误日志为空。
- 本机未安装 Inno Setup，未在本地生成新的安装器；推送 `v0.1.2` tag 后由 GitHub Actions 构建 `QuotaDock-Setup-0.1.2.exe` 和 SHA-256 文件。

## 安全边界

本次改动未读取、提交或上传任何 Cookie、凭证或真实额度数据。更新按钮只检查公开 GitHub Release，并由用户决定是否打开下载页。
