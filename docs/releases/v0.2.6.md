# QuotaDock v0.2.6

## Windows PowerShell 5.1 兼容

- 启动器（VBS）、管理中心、小浮窗、更新器、自检改为：**优先 pwsh（PowerShell 7+），缺失时回退到系统自带 `powershell.exe`（5.1）**。
- 安装器不再把「未装 PowerShell 7」当成硬性阻塞提示；仅在连 5.1 都找不到时提示，并可打开 aka.ms 下载页。
- 为含中文的 `.ps1` 补齐 UTF-8 BOM，避免 Windows PowerShell 5.1 误解析脚本。

## SmartScreen / 未签名

- **无法在没有代码签名证书时消除** SmartScreen「未知发布者」提示；本版继续加强文档与首次运行说明（核对 SHA-256 → 仍要运行）。
- 启动器在完全找不到 PowerShell 时，中文对话框可选择打开 PowerShell 7 下载页。
- 文档补充 OV/EV 代码签名建议路径；本仓库维护者不提供付费证书私钥。

## 文档

- README / 下载指南 / 部署指南 / 故障排查：系统要求改为 Windows PowerShell 5.1+（推荐 7+）。
- 首次运行新手引导增加 SmartScreen 与 5.1 兼容提示。

## 下载

- `QuotaDock-Setup-0.2.6.exe`：Windows 安装器
- `QuotaDock-v0.2.6.zip`：Windows 便携/本地更新包
- `QuotaDock-macOS-v0.2.6.zip`：macOS 原生预览包（Apple Silicon arm64）

## 已知边界

- SmartScreen 真正消失需要 OV/EV **代码签名证书**（付费）；本版未包含签名。
- Claude 官方同步脚本、Muse Cookie GUI 写入器仍未纳入。
- 构建机 / CI 仍可使用 `pwsh`；最终用户不再被强制安装 PowerShell 7。
