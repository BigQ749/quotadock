# QuotaDock 0.1.5 · 凭证路径兼容与自动续期版

## 这版解决什么

- OpenCode Go 兼容读取旧版 `%LOCALAPPDATA%\QuotaFusionDesktop\opencode_go_credentials.json`，不需要因为升级路径变化而重复复制 Cookie。
- OpenCode Go 后台直连继续把成功时间、尝试时间和失败原因分开记录。
- Grok 同步器在 access token 临近过期或接口返回 401/403 时，优先使用 OAuth `refresh_token` 自动换取新 token；只有刷新凭证被撤销或缺失时才需要重新登录。

## 验证边界

- OpenCode Go 使用本机旧凭证直连官方页面返回 HTTP 200，并解析出 3 个额度窗口。
- Grok 当前接口探测成功，后台同步保持单实例运行。
- 不把 Cookie、Token、真实额度快照或个人路径写入仓库和更新包。
